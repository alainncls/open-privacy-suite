❯ please explain - ther eis a threshold in Config tab of compliance, above  
  which the travel rules apply. but on tavel rules tab I can create a       
  record with amount. So how does this amount correlate with the one in     
  config ?                                                                  

⏺ Good question. Here's how it works:

  Config threshold = the USD amount above which a transfer is blocked unless a
  travel rule record exists.

  Travel rule record amount = the USD amount the admin pre-authorizes for a
  specific user-to-address transfer.

  The flow:

  1. Admin sets threshold to $3,000 in Config
  2. User tries to send $5,000 worth of ETH to 0xabc...
  3. Proxy intercepts the transaction, calculates USD value using token prices
  4. $5,000 > $3,000 threshold → proxy checks: is there a valid (unused,
  unexpired) travel rule record for this user sending to 0xabc...?
  5. No record → transaction denied
  6. Record exists → transaction allowed, record marked as "used"

  So the amount on the travel rule record doesn't need to match exactly — it's
  metadata for audit/compliance purposes (documenting what transfer was
  authorized). The matching is done by originator user + beneficiary address +
  transfer type.

  The amount_wei and amount_usd on the record are there because travel rule
  regulations (FATF) require documenting the expected transfer value as part of
  the originator/beneficiary data exchange.

  TL;DR: Config threshold triggers the check, travel rule record satisfies the
  check. The record's amount is for regulatory documentation, not for matching.
