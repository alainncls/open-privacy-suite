## JSON-RPC Proxy

<ApiEndpoint method="POST" path="/" description="Forward JSON-RPC request to Ethereum node" />

**Headers:** `Authorization: Bearer <access_token>`

**Body:**

```json
{
  "jsonrpc": "2.0",
  "method": "eth_call",
  "params": ["..."],
  "id": 1
}
```

**Access control pipeline:**

1. Validates JWT
2. Checks user KYC status and ban flag
3. Validates method against allowlist
4. Validates contract address (if applicable)
5. Enforces rate limits

### Contracts

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/api/orgs/:org_id/contracts` | List contracts |
| POST | `/api/orgs/:org_id/contracts` | Register a contract (internal/proxy-deployed) |
| POST | `/api/orgs/:org_id/contracts/claim` | Claim an on-chain contract with proof of deployment |
| PUT | `/api/orgs/:org_id/contracts/:addr` | Update contract |
| DELETE | `/api/orgs/:org_id/contracts/:addr` | Delete contract |

The list contracts endpoint supports optional filters:
- `?search=term` — filter by contract name or address prefix (case-insensitive)
- `?created_after=timestamp` — return contracts created after this date
- `?created_before=timestamp` — return contracts created before this date

**Body (register):**

```json
{
  "contract_address": "0x...",
  "owner_group_id": "uuid",
  "metadata": {}
}
```

**Body (claim):** For claiming contracts deployed outside the proxy. Requires the deployment transaction hash as proof. The proxy verifies the receipt's `contractAddress` matches and the address has bytecode on-chain. All verification failures return an opaque error to prevent address existence disclosure.

```json
{
  "address": "0x...",
  "name": "My Contract",
  "deployment_tx_hash": "0x..."
}
```

## Error Responses

All errors follow a consistent format:

```json
{
  "error": "error_code",
  "message": "Human readable message"
}
```

### Status Codes

| Status | Meaning |
|--------|---------|
| `400` | Bad request or validation error |
| `401` | Missing or invalid authentication |
| `403` | Forbidden (banned, no KYC, method not allowed) |
| `404` | Resource not found |
| `429` | Rate limit exceeded |
| `500` | Internal server error |
