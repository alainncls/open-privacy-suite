## What's Already Strong

The privacy-proxy is significantly more hardened than the block-explorer:

- **RBAC**: 5,159 lines of tests, cross-org isolation verified, 70+ blocked methods
- **JWT**: Algorithm binding (HMAC only), signature verified, expiry enforced
- **Admin auth**: Multi-layer (localhost CIDR + token/JWT), constant-time comparison
- **Race conditions**: All maps mutex-protected, cache has concurrent tests
- **Resource leaks**: All cleaned up on shutdown, goroutines tracked with WaitGroups
- **Context propagation**: All DB calls use ctx
- **Hash chain**: Mutex-protected SHA256, tamper-evident
- **Grant expiration/revocation**: DB-level enforcement with NOW() check
- **SQL**: All parameterised — no injection vectors found
- **Disclosure**: 3,953 lines of tests covering full workflow

## Recommended Test Infrastructure

2. **Admin endpoint test helper** — Generic setup that creates org → group → user → membership → contract → grant, so each admin test doesn't repeat boilerplate.
3. **Error injection middleware** — Mock that can simulate DB timeout, RPC 503, privacy-proxy down at specific points in the handler chain.
4. **`go test -race` in CI** — Already configured in Makefile, ensure CI runs it.
